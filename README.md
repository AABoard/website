# Obsolete AAB Static Website Repository

This repository is retained only as a historical/static website reference for AAB.

## Current Website Repository

Active website work should happen in:

- `AABoard/aab-dynamic-website`

The dynamic website repository is the intended source for the current AAB public website architecture, including Next.js routes, MongoDB-backed registry data, API routes, and local JSON fallback data.

## Status

- Repository status: obsolete static reference.
- Do not use this repository for new website development.
- Do not add new registry data here.
- Do not store MongoDB credentials or environment files here.

## Historical Context

The International AI Assessment Board (AAB) is a nonprofit initiative dedicated to advancing AI literacy and AI education standards across K-12 education, adult learning, and workforce AI training.

AAB maintains open AI education case and pilot registry infrastructure to document real-world AI learning programs and support evidence-based AI education research.

Visit [https://aaboard.org](https://aaboard.org).
